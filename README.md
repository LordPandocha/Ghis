# GHIS

Новый сайт GHIS. Визуальные решения пересобраны с чистого листа.

## Единственное сохранённое дизайн-ограничение: палитра

- Тёплый молочный фон: `#f7f2eb`
- Пудрово-розовый акцент: `#e9c9cc`
- Приглушённый розовый: `#c68f98`
- Тёмно-коричневый текст: `#30231f`
- Тёплый бежевый: `#ded0c4`
- Приглушённый серо-коричневый для вторичного текста: `#85766e`

Остальные дизайн-решения не считаются обязательными и могут проектироваться заново.
