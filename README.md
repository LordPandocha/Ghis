# Ghis — сайт-визитка визажиста

Статический адаптивный сайт для демонстрационного макета персонального beauty-сайта.

## Запуск
Откройте `index.html` в браузере. Для публикации на GitHub Pages загрузите `index.html` и папку `assets/` в корень репозитория и включите Pages в Settings → Pages → Deploy from a branch → main / root.

## Перед публикацией
- Согласуйте с Кристиной использование фотографий и публикацию сайта.
- Уточните и добавьте реальные цены, условия записи и дополнительные контакты.
- Фотографии в `assets/` — фрагменты предоставленного скриншота профиля, обрезанные для демонстрации.
