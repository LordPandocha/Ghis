Открыто о конфиденциальности.

Здесь описано, что происходит с данными при посещении этого сайта. Информация относится к текущей версии сайта на GitHub Pages.

🍪 Cookies и аналитика

Сайт не устанавливает собственные cookie-файлы, не использует счётчики посещений, рекламные пиксели или браузерное хранилище для отслеживания посетителей. Поэтому плашка согласия на необязательные cookies сейчас не показывается.

Если в будущем появятся аналитика, формы или встроенные сервисы, эта страница будет обновлена до их подключения.

🌐 Хостинг

Сайт размещён на GitHub Pages. По информации GitHub, при посещении страниц сервис записывает IP-адрес посетителя в целях безопасности. Обработка этих данных описана в политике GitHub.

🔗 Внешние сайты

Кнопки Instagram открывают отдельный сайт только после вашего перехода. Его правила обработки данных определяются владельцем этого сервиса. Встроенных публикаций Instagram, которые загружаются автоматически, здесь нет.

✉️ Связь

На сайте нет формы обратной связи. Если вы решите написать через Instagram, сообщение будет обрабатываться в этом сервисе. По вопросам содержания сайта можно обратиться через публичный профиль Алёши Семёнова.

Обновления

Если на сайте появятся сбор заявок, покупки, аналитика или другие сервисы, условия обработки данных и необходимые способы получения согласия будут пересмотрены до запуска новых функций.
